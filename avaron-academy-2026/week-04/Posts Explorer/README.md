# Posts Explorer App

A simple, responsive web application built with **HTML, CSS, and JavaScript** that allows users to fetch, explore, search, and filter posts from the [JSONPlaceholder API](https://jsonplaceholder.typicode.com/).

## Features

- **Fetch Posts:** Retrieve posts dynamically from an external API.
- **Search:** Search posts by title in real time.
- **User Filter:** Filter posts by User ID.
- **Load More:** Display posts in batches for easier browsing.
- **Reload Posts:** Fetch posts again whenever needed.
- **Dark Mode:** Switch between light and dark themes.
- **Loading & Error Messages:** Display useful feedback during API requests.
- **Responsive Design:** Works across desktop and mobile screens.

## Technologies Used

- HTML5: Application structure.
- CSS3: Styling and responsive layout.
- JavaScript (ES6+): Application logic and DOM manipulation.
- Fetch API: Retrieving data from the server.
- JSONPlaceholder: Free test API for sample posts.
- Local Storage: Saving the user's theme preference.

## Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `searcPosts.html` in your browser.

No additional installation is required.
