# Greeting Master 👋

A simple, interactive web application built with **HTML, CSS, and JavaScript** that welcomes users with personalized greetings based on the time of day.

Greeting Master allows users to enter their names, view the current time, and enjoy a customized greeting with a welcome message. It also includes a background-changing feature for a more interactive user experience.

## ✨ Features

- **🕒 Current Time Display:** Displays the current time.
- **⏰ Show  TimCe button that allows users to display the current time.
- **🎨 Change Background:** Change the app's background for a fresh visual experience.
- **👋 Personalized Greeting:** Enter your name and receive a customized welcome message.
- **🌅 Time-Based Greetings:** Automatically selects an appropriate greeting:
  - Good morning
  - Good afternoon
  - Good evening
- **📝 User Name Input:** Accepts the user's name through an input field.
- **🚀 Greet Me Button:** Displays a personalized greeting based on the entered name and current time.

## 🛠️ Technologies Used

- **HTML5** — Structures the web application.
- **CSS3** — Styles the interface and manages its visual appearance.
- **JavaScript** — Implements the interactive features, time detection, and personalized greeting logic.

## 🚀 Getting Started

Follow these steps to run the application locally.

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/idrisibrahimabbah/averon-academy-week-01.git
   ```

2. Navigate to the project folder:

   ```bash
   cd greeting-master
   ```

3. Open `index.html` in your web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

## 📖 How to Use

1. Open the Greeting Master application.
2. Enter your name in the input field.
3. Click the **Greet Me** button.
4. Receive a personalized greeting based on the current time of day.
5. Click **Show Time** to display the current time.
6. Click **Change Theme** to change the page's background.
